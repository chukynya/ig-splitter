01 / OFFICIAL

What Instagram actually publishes.

Meta’s Instagram Help Centre says shared photos are uploaded at the best available resolution up to a width of 1080 px. A photo between 320 and 1080 px wide is kept at its original resolution when its aspect ratio is between 1.91:1 and 3:4. Unsupported ratios can be cropped.

To target the maximum documented width, Meta advises using the latest Instagram app, uploading an image at least 1080 px wide within that ratio range, and using a device with a high-quality camera.

Primary source
Instagram Help Centre — Image resolution of photos you share on Instagram ↗

The often-repeated “30 MB maximum” is not stated on that public photo-resolution page. IG Splitter uses 30 MB only as a browser-memory guardrail for each source file; it is not presented as an official Instagram upload limit.

02 / PRACTICAL SIZES

Choose the surface, then the ratio.

“Supported” and “recommended” are different. The 4:5 portrait is a practical feed-first default because it uses substantial vertical space while staying inside Meta’s documented range. A 3:4 image is taller and also falls on the documented portrait boundary.

Carousel rule

Keep every carousel slide at the same ratio. IG Splitter center-crops the source once, then takes adjacent slices from that crop. It adds no artificial gap between slides, so the right edge of one slide continues directly into the left edge of the next.

03 / PROFILE GAP

The gap is UI, not image data.

There is no fixed official gap-width specification.
Meta’s public image-resolution guidance does not publish a profile-grid gap in pixels. The rendered space can vary with device, viewport, app version, and interface changes.

A seamless mural can look slightly stretched when the app inserts space between adjacent thumbnails. Gap compensation skips a matching sliver of source artwork at every tile boundary. The screen gap then occupies the place of that skipped artwork.

Why the tool starts at 10 px

Ten design pixels relative to a 1350 px-tall post is a practical starting point from the referenced IG Split workflow. Grid Maker now follows that workflow’s same 1015 px preview estimate and source-derived output size. Enter 0 to disable compensation.

Calibrate for your own screen

  1. Take a screenshot of your profile grid.
  2. Measure one tile’s displayed height and the gap beside it.
  3. Convert that measurement to the 1350 px design scale.
design gap = round(screen gap ÷ screen tile height × 1350)

Example: a 3 px screen gap beside a 405 px-tall tile becomes 10 design px (3 ÷ 405 × 1350).

Grid Maker’s planning model

The reference workflow estimates the centered profile preview as 1015 px wide inside each 1080 × 1350 design unit. For g gap pixels and r rows:

width = 1080 + 2 × (1015 + g)
height = r × (1350 + g)

The source can differ from that ideal canvas. Grid Maker uses the available source height or width, center-crops horizontally when needed, removes the planned gaps, and keeps the resulting 4:5 slices at their source-derived size. A 3240 × 4050 source with three rows and a 10 px gap therefore produces nine 1072 × 1340 files without upscaling.

04 / QUALITY

Lossless here. Instagram is separate.

All processing happens with the browser’s Canvas API on this device. IG Splitter exports PNG, so downloading a tile does not add JPEG compression artifacts. ZIP downloads store those same PNG bytes unchanged.

Carousel output is resized to its selected 1080 px-wide format. Grid Maker instead preserves its source-derived slice dimensions, avoiding an unnecessary upscale. For the crispest result in either mode, start with enough source resolution for every tile.

Important limit
Instagram may still resize, crop, or recompress an image after upload. No independent static tool can guarantee the pixels Instagram ultimately serves.

Posting order for a profile mural

Downloaded grid files are numbered for posting: 01 is the bottom-right tile, then move right-to-left and bottom-to-top. Upload 01 first. Once every file is posted, the highest number sits at the top-left of the finished mural.
